For the items in the matrix marked with `✓ (FFmpeg)`, asbplayer automatically uses FFmpeg to convert the audio to WebM Opus, with an alert indicating that conversion is happening. Browsers with Media Source Extensions can start playback while conversion continues, with seeking limited to buffered audio. The seek bar shows that buffer, which may trail conversion progress. Browsers that support WebM Opus playback without Media Source Extensions (iPhone) wait for conversion to finish before playing. Mining uses an immutable snapshot of the audio available when the card is created. This uses the <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>FFmpeg library compiled for asbplayer</a>, which is fetched on first use and cached for offline use.

### Streaming services and subtitle detection {#streaming-services-and-subtitle-detection}

:::tip
For streaming services not listed below, asbplayer can attempt a best-effort generic subtitle detection which works for ~85% of websites.

You can always request a dedicated parser for any website, even if the generic parser detects subtitles, through an <a href={`${project.urls.repo}/issues`}>issue</a> or submit your own implementation in a <a href={`${project.urls.repo}/pulls`}>PR</a> on GitHub.
:::
