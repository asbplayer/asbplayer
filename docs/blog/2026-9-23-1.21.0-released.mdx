Extension v1.21.0 has been released.

<!-- truncate -->

Lots of enhancements and bug fixes were included in this release.

- As usual [@ShanaryS](https://github.com/ShanaryS) made very large contributions to this release. Notably, asbplayer now supports generic subtitle detection for websites it doesn't explicitly support, with around 85% efficacy from his own testing.
- MvJ Primed Listening is now supported thanks to play mode enhancements by [@JayXT](https://github.com/JayXT)
- [@xwxb](https://github.com/xwxb) continues to own the Jimaku integration and implemented episode number auto-detection.
- A long-time bug where the Anki card browser doesn't refresh was fixed by [@mvanhorn](https://github.com/mvanhorn)
- Crunchyroll subtitle detection was added by [@cbgmvinicius](https://github.com/cbgmvinicius) and subtitle visibility in fullscreen was fixed by [@rajpiskala](https://github.com/rajpiskala).
- Stremio subtitle detection was fixed by [@eXaminator](https://github.com/eXaminator)

Thanks to all the contributors both old and new for making this release possible. Full release notes can be read here:
[v1.21.0](https://github.com/asbplayer/asbplayer/releases/tag/v1.21.0)
