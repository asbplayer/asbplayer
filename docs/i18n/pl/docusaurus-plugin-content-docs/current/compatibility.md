W pozycjach tabeli oznaczonych `✓ (FFmpeg)` asbplayer automatycznie konwertuje dźwięk do odtwarzanego formatu. Obsługiwane przeglądarki mogą rozpocząć odtwarzanie w trakcie konwersji, ale przewijanie jest ograniczone do już dostępnego dźwięku. Pozostałe przeglądarki czekają na zakończenie konwersji. <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>Biblioteka FFmpeg skompilowana dla asbplayera</a> jest pobierana przy pierwszym użyciu i zapisywana do użytku offline.

### Serwisy strumieniowe i wykrywanie napisów {#streaming-services-and-subtitle-detection}

:::tip
W przypadku niewymienionych poniżej serwisów strumieniowych asbplayer może spróbować ogólnego wykrywania napisów, które działa na około 85% stron.

Możesz poprosić o osobny parser dla dowolnej strony — nawet jeśli ogólny parser wykrywa na niej napisy — zgłaszając <a href={`${project.urls.repo}/issues`}>problem</a> albo przesłać własną implementację w <a href={`${project.urls.repo}/pulls`}>PR-ze</a> na GitHubie.
:::
