# Korzystanie offline {#offline-usage}

Ze <a href={project.urls.app}>strony</a> można korzystać offline dzięki obsłudze PWA przez [vite-pwa](https://vite-pwa-org.netlify.app/). Aktualizacje zostaną pobrane przy następnym otwarciu strony z dostępem do internetu.

## Dodawanie do ekranu głównego {#add-to-home-screen}

Stronę można dodać do ekranu głównego urządzenia z Androidem jako progresywną aplikację internetową. W menu przeglądarki wybierz „Dodaj do ekranu głównego”.
