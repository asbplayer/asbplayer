# Wybór ścieżki dźwiękowej {#audio-track-selection}

Niektóre pliki wideo mają kilka ścieżek dźwiękowych. Na stronie można wybrać ścieżkę dźwiękową po włączeniu flagi **Experimental Web Platform features** na stronie `chrome://flags` (lub jej odpowiedniku w używanej przeglądarce).

:::warning
W chwili pisania tego tekstu flaga **Experimental Web Platform features** całkowicie uniemożliwia działanie rozszerzenia przeglądarki podczas odtwarzania wideo strumieniowego (na niektórych, a być może wszystkich stronach). Włącz ją na własne ryzyko.
:::
