# 오프라인 사용 {#offline-usage}

[vite-pwa](https://vite-pwa-org.netlify.app/)를 통한 PWA 지원 덕분에 <a href={project.urls.app}>웹사이트</a>를 오프라인에서도 사용할 수 있습니다. 인터넷에 연결된 상태에서 웹사이트에 다시 접속하면 업데이트를 가져옵니다.

## 홈 화면에 추가하기 {#add-to-home-screen}

웹사이트는 프로그레시브 웹 앱이므로 Android 기기의 홈 화면에 추가할 수 있습니다. 브라우저 메뉴에서 "홈 화면에 추가"를 탭합니다.
