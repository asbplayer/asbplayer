# 오디오 트랙 선택 {#audio-track-selection}

일부 동영상 파일에는 오디오 트랙이 여러 개 있습니다. 웹사이트에서는 `chrome://flags`(또는 사용 중인 브라우저의 해당 페이지)에서 **Experimental Web Platform features** 플래그를 사용 설정하면 오디오 트랙을 선택할 수 있습니다.

:::warning
현재 **Experimental Web Platform features**를 사용 설정하면 일부 또는 모든 웹사이트에서 스트리밍 동영상용 브라우저 확장 프로그램이 제대로 작동하지 않습니다. 이 플래그는 주의해서 사용하세요.
:::
