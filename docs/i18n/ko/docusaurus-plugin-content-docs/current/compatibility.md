표에서 `✓ (FFmpeg)`로 표시된 항목은 asbplayer가 오디오를 재생 가능한 형식으로 자동 변환합니다. 지원 브라우저에서는 변환 중에도 재생을 시작할 수 있지만, 탐색 가능한 범위는 변환된 오디오에 한정됩니다. 그 밖의 브라우저에서는 변환이 끝날 때까지 기다립니다. <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>asbplayer용으로 컴파일된 FFmpeg 라이브러리</a>는 처음 사용할 때 다운로드되며 오프라인 사용을 위해 캐시됩니다.
