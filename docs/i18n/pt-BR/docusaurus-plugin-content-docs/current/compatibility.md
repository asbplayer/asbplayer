| **Navegadores baseados no Chromium** |        ✓        |        ✓        |                 |                                          ✓                                           |         [Depende da plataforma/decodificador](https://www.chromium.org/audio-video/)         |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Firefox**                 |        ✓        |        ✓        |                 | [Depende dos codecs do sistema](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) | [Depende dos codecs do sistema](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Safari**                  |        ✓        |                 |                 |                                          ✓                                           |                                          ✓                                           |                      ✓                       |        ✓ (FFmpeg)        |

Para os itens da tabela marcados com `✓ (FFmpeg)`, o asbplayer converte automaticamente o áudio para um formato reproduzível. Os navegadores compatíveis podem iniciar a reprodução enquanto a conversão continua, mas só é possível avançar até o trecho de áudio disponível; os demais aguardam a conclusão da conversão. A <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>biblioteca FFmpeg compilada para o asbplayer</a> é baixada no primeiro uso e armazenada em cache para uso offline.

### Serviços de streaming e detecção de legendas {#streaming-services-and-subtitle-detection}

:::tip
Para serviços de streaming que não estão listados abaixo, o asbplayer pode tentar uma detecção genérica de legendas, que funciona em cerca de 85% dos sites.

Você pode solicitar um analisador específico para qualquer site, mesmo que o analisador genérico detecte as legendas, abrindo uma <a href={`${project.urls.repo}/issues`}>issue</a> ou enviando sua própria implementação em um <a href={`${project.urls.repo}/pulls`}>PR</a> no GitHub.
:::
