# 音声トラックの選択 {#audio-track-selection}

動画ファイルによっては複数の音声トラックがあります。ウェブサイトでは、`chrome://flags`（または使用中のブラウザーの同等の設定）で**Experimental Web Platform features**フラグを有効にすると、音声トラックを選択できます。

:::warning
この記事の執筆時点では、**Experimental Web Platform features**を有効にすると、ストリーミング動画でブラウザー拡張機能が完全に動作しなくなります（一部、またはすべてのウェブサイトで発生する可能性があります）。このフラグはご自身の判断で有効にしてください。
:::
