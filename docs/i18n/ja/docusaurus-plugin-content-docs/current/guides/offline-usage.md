# オフラインでの使用 {#offline-usage}

<a href={project.urls.app}>ウェブサイト</a>は[vite-pwa](https://vite-pwa-org.netlify.app/)によるPWA対応のおかげで、オフラインでも使用できます。更新は、次にインターネット接続中にウェブサイトへアクセスしたときに取得されます。

## ホーム画面に追加 {#add-to-home-screen}

プログレッシブウェブアプリとして、ウェブサイトをAndroid端末のホーム画面に追加できます。ブラウザーのメニューから「ホーム画面に追加」をタップしてください。
