# 互換性 {#compatibility}

## ウェブサイト {#website}

### ブラウザーと音声・動画形式 {#browsers-and-media-formats}

| ブラウザー                     | `mp4` コンテナ | `mkv` コンテナ | `avi` コンテナ |                                        H.264                                         |                                      H.265/HEVC                                      | Dolby Digital / Digital Plus (AC-3 / E-AC-3) | DTS / Dolby TrueHD / MLP |
| --------------------------- | :-------------: | :-------------: | :-------------: | :----------------------------------------------------------------------------------: | :----------------------------------------------------------------------------------: | :------------------------------------------: | :----------------------: |
| **Chromiumベースのブラウザー** |        ✓        |        ✓        |                 |                                          ✓                                           |         [プラットフォーム／デコーダーによる](https://www.chromium.org/audio-video/)         |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Firefox**                 |        ✓        |        ✓        |                 | [OSのコーデックによる](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) | [OSのコーデックによる](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Safari**                  |        ✓        |                 |                 |                                          ✓                                           |                                          ✓                                           |                      ✓                       |        ✓ (FFmpeg)        |

表中で `✓ (FFmpeg)` と示された項目では、asbplayerが音声を再生可能な形式に自動変換します。対応ブラウザーでは変換中に再生を開始できますが、シークできる範囲は変換済みの音声に限られます。それ以外のブラウザーでは変換の完了を待ちます。<a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>asbplayer用にコンパイルされたFFmpegライブラリー</a>は初回使用時にダウンロードされ、オフライン利用向けにキャッシュされます。

### ストリーミングサービスと字幕検出 {#streaming-services-and-subtitle-detection}

:::tip
以下に記載されていないストリーミングサービスでは、asbplayerは汎用字幕検出を試みます。これは約85%のウェブサイトで動作します。

汎用パーサーが字幕を検出できる場合も、どのウェブサイトについても<a href={`${project.urls.repo}/issues`}>イシュー</a>で専用パーサーをリクエストできます。または、GitHubで独自の実装を<a href={`${project.urls.repo}/pulls`}>PR</a>として提出してください。
:::
