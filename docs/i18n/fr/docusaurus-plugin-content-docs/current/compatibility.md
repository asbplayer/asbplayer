| Navigateur                  | Conteneur `mp4` | Conteneur `mkv` | Conteneur `avi` |                                        H.264                                         |                                      H.265/HEVC                                      | Dolby Digital / Digital Plus (AC-3 / E-AC-3) | DTS / Dolby TrueHD / MLP |

| **Navigateurs basés sur Chromium** |        ✓        |        ✓        |                 |                                          ✓                                           |         [Dépend de la plateforme/du décodeur](https://www.chromium.org/audio-video/)         |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Firefox**                 |        ✓        |        ✓        |                 | [Dépend des codecs du système d’exploitation](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) | [Dépend des codecs du système d’exploitation](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Safari**                  |        ✓        |                 |                 |                                          ✓                                           |                                          ✓                                           |                      ✓                       |        ✓ (FFmpeg)        |

Pour les éléments du tableau marqués `✓ (FFmpeg)`, asbplayer convertit automatiquement l’audio dans un format lisible. Les navigateurs compatibles peuvent lancer la lecture pendant la conversion, mais les déplacements dans la vidéo sont limités à la partie audio disponible ; les autres attendent la fin de la conversion. La <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>bibliothèque FFmpeg compilée pour asbplayer</a> est téléchargée lors de la première utilisation et mise en cache pour une utilisation hors ligne.

### Services de streaming et détection des sous-titres {#streaming-services-and-subtitle-detection}

:::tip
Pour les services de streaming non répertoriés ci-dessous, asbplayer peut tenter une détection générique des sous-titres, qui fonctionne sur environ 85 % des sites web.

Vous pouvez demander un analyseur dédié pour n’importe quel site, même si l’analyseur générique détecte les sous-titres, en ouvrant un <a href={`${project.urls.repo}/issues`}>ticket</a>. Vous pouvez aussi proposer votre propre implémentation dans une <a href={`${project.urls.repo}/pulls`}>PR</a> sur GitHub.
:::
