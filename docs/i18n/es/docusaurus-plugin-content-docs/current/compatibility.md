Para los elementos de la tabla marcados con `✓ (FFmpeg)`, asbplayer convierte automáticamente el audio a un formato reproducible. Los navegadores compatibles pueden empezar la reproducción mientras continúa la conversión, aunque solo se puede avanzar por el audio disponible; los demás esperan a que termine. La <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>biblioteca de FFmpeg compilada para asbplayer</a> se descarga la primera vez que se usa y se guarda en caché para usarla sin conexión.

### Servicios de streaming y detección de subtítulos {#streaming-services-and-subtitle-detection}

:::tip
En los servicios de streaming que no aparecen a continuación, asbplayer puede intentar una detección genérica de subtítulos que funciona en aproximadamente el 85 % de los sitios web.

Siempre puedes solicitar un analizador específico para cualquier sitio web, aunque el analizador genérico detecte sus subtítulos, mediante una <a href={`${project.urls.repo}/issues`}>incidencia</a> o enviar tu propia implementación en un <a href={`${project.urls.repo}/pulls`}>PR</a> en GitHub.
:::
