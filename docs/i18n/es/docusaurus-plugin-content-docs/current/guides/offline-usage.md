# Uso sin conexión {#offline-usage}

El <a href={project.urls.app}>sitio web</a> puede usarse sin conexión gracias a la compatibilidad con PWA mediante [vite-pwa](https://vite-pwa-org.netlify.app/). Las actualizaciones se descargan la próxima vez que se accede al sitio web con conexión a Internet.

## Añadir a la pantalla de inicio {#add-to-home-screen}

Como aplicación web progresiva, puedes añadir el sitio web a la pantalla de inicio de tu dispositivo Android. En el menú del navegador, pulsa «Añadir a la pantalla de inicio».
