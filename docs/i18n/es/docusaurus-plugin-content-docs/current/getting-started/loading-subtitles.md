# Cargar subtítulos {#loading-subtitles}

El primer paso para usar asbplayer es cargar subtítulos en una fuente de vídeo.

## Vídeo en streaming {#streaming-video}

### Chrome (u otros navegadores basados en Chromium) {#chromium}

1. Instala la extensión de Chrome desde la <a href={project.extension.chrome.storeUrl}>tienda web</a> de Google o desde la <a href={`${project.urls.repo}/releases/latest`}>versión de GitHub</a>.
2. Haz clic en el icono 🧩 de la barra de herramientas del navegador → asbplayer → **Abrir panel lateral**.
3. Haz clic en **Cargar subtítulos** para cargarlos en cualquier vídeo de la página actual.

### Firefox {#firefox}

:::warning
asbplayer no incluye algunas funciones en Firefox. Consulta la sección de [compatibilidad](../compatibility.md#extension).  
:::

1. Instala el complemento de Firefox desde la <a href={project.extension.firefox.storeUrl}>tienda de complementos</a> de Mozilla o desde la <a href={`${project.urls.repo}/releases/latest`}>versión de GitHub</a>.
2. Haz clic en el icono 🧩 de la barra de herramientas del navegador → asbplayer → **Abrir panel lateral**.
3. Haz clic en **Cargar subtítulos** para cargarlos en cualquier vídeo de la página actual.

### Android {#android}

Consulta la [guía de Android](../guides/android.md).

## Archivos de vídeo {#video-files}

1. Abre el <a href={project.urls.app}>sitio web</a>.
2. Arrastra los archivos de vídeo y subtítulos al sitio web.
