Matriisissa merkityissä `✓ (FFmpeg)`-kohdissa asbplayer muuntaa äänen automaattisesti toistettavaan muotoon. Tuetut selaimet voivat aloittaa toiston muunnoksen jatkuessa, mutta siirtyminen on rajattu saatavilla olevaan ääneen; muut selaimet odottavat muunnoksen valmistumista. <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>asbplayerille käännetty FFmpeg-kirjasto</a> ladataan ensimmäisellä käyttökerralla ja tallennetaan välimuistiin offline-käyttöä varten.

### Suoratoistopalvelut ja tekstitysten tunnistus {#streaming-services-and-subtitle-detection}

:::tip
Alla mainitsemattomissa suoratoistopalveluissa asbplayer voi kokeilla yleistä tekstitysten tunnistusta, joka toimii noin 85 prosentissa verkkosivustoista.

Voit aina pyytää tietylle verkkosivustolle omaa jäsennintä, vaikka yleinen jäsennin tunnistaisi tekstitykset. Tee se <a href={`${project.urls.repo}/issues`}>ongelmailmoituksella</a> tai lähetä oma toteutuksesi GitHubin <a href={`${project.urls.repo}/pulls`}>PR:nä</a>.
:::
