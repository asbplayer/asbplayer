# Offline-käyttö {#offline-usage}

<a href={project.urls.app}>Verkkosivustoa</a> voi käyttää offline-tilassa [vite-pwa](https://vite-pwa-org.netlify.app/)-kirjaston tarjoaman PWA-tuen ansiosta. Päivitykset ladataan, kun verkkosivustoa seuraavan kerran käytetään internetyhteyden ollessa käytettävissä.

## Lisää aloitusnäyttöön {#add-to-home-screen}

Progressiivisena verkkosovelluksena verkkosivuston voi lisätä Android-laitteen aloitusnäyttöön. Valitse selaimen valikosta ”Lisää aloitusnäyttöön”.
