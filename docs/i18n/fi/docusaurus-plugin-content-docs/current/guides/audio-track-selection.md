# Ääniraidan valinta {#audio-track-selection}

Joissakin videotiedostoissa on useita ääniraitoja. Verkkosivustolla ääniraidan voi valita, kun **Experimental Web Platform features** -asetus on käytössä osoitteessa `chrome://flags` (tai nykyisen selaimen vastaavassa paikassa).

:::warning
Tätä kirjoitettaessa **Experimental Web Platform features** rikkoo selainlaajennuksen suoratoistovideon käytön kokonaan (joillakin verkkosivustoilla, mahdollisesti kaikilla). Ota asetus käyttöön omalla vastuullasi.
:::
