### 浏览器和音视频格式 {#browsers-and-media-formats}

| 浏览器                      | `mp4` 容器      | `mkv` 容器      | `avi` 容器      |                                        H.264                                         |                                      H.265/HEVC                                      | Dolby Digital / Digital Plus (AC-3 / E-AC-3) | DTS / Dolby TrueHD / MLP |
| --------------------------- | :-------------: | :-------------: | :-------------: | :----------------------------------------------------------------------------------: | :----------------------------------------------------------------------------------: | :------------------------------------------: | :----------------------: |
| **基于 Chromium 的浏览器** |        ✓        |        ✓        |                 |                                          ✓                                           |         [取决于平台/解码器](https://www.chromium.org/audio-video/)                     |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Firefox**                 |        ✓        |        ✓        |                 | [Depends on OS codecs](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) | [Depends on OS codecs](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Safari**                  |        ✓        |                 |                 |                                          ✓                                           |                                          ✓                                           |                      ✓                       |        ✓ (FFmpeg)        |

对于表格中标有 `✓ (FFmpeg)` 的项目，asbplayer 会自动将音频转换为可播放的格式。支持的浏览器可以在转换期间开始播放，但只能定位到已转换的音频部分；其他浏览器则会等待转换完成。首次使用时会下载为 asbplayer 编译的 <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>FFmpeg 库</a>，并缓存以供离线使用。

### 流媒体服务和字幕检测 {#streaming-services-and-subtitle-detection}

:::tip
对于下方未列出的流媒体服务，asbplayer 可以尝试使用通用字幕检测，尽力适配约 85% 的网站。

即使通用解析器能够检测到字幕，你也可以通过<a href={`${project.urls.repo}/issues`}>问题</a>请求为任意网站开发专用解析器，或在 GitHub 上提交自己的实现<a href={`${project.urls.repo}/pulls`}>PR</a>。
:::
