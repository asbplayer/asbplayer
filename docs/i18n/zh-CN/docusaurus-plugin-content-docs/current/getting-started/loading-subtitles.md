# 加载字幕 {#loading-subtitles}

使用 asbplayer 的第一步，是为视频来源加载字幕。

## 流媒体视频 {#streaming-video}

### Chrome（或其他基于 Chromium 的浏览器）{#chromium}

1. 从 Google <a href={project.extension.chrome.storeUrl}>网上应用店</a>或 <a href={`${project.urls.repo}/releases/latest`}>GitHub 发布页</a>安装 Chrome 扩展。
2. 点击浏览器工具栏中的 🧩 图标 → asbplayer → **打开侧边栏**
3. 点击**加载字幕**，即可为当前页面上的任意视频加载字幕。

### Firefox {#firefox}

:::warning
asbplayer 在 Firefox 上缺少一些功能。请参阅[兼容性](../compatibility.md#extension)部分。  
:::

1. 从 Mozilla <a href={project.extension.firefox.storeUrl}>附加组件商店</a>或 <a href={`${project.urls.repo}/releases/latest`}>GitHub 发布页</a>安装 Firefox 附加组件。
2. 点击浏览器工具栏中的 🧩 图标 → asbplayer → **打开侧边栏**
3. 点击**加载字幕**，即可为当前页面上的任意视频加载字幕。

### Android {#android}

请参阅 [Android 指南](../guides/android.md)。

## 视频文件 {#video-files}

1. 打开<a href={project.urls.app}>网站</a>。
2. 将视频和字幕文件拖放到网站中。
