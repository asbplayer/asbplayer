# 字幕时间同步 {#subtitle-timing}

字幕文件经常与加载它们的视频源不同步。为此，asbplayer 提供了手动调整字幕时间的方法。

## 键盘快捷键 {#keyboard-shortcuts}

修正字幕时间最快的方法是使用[字幕偏移键盘快捷键](../reference/settings.md#subtitle-offset-keyboard-shortcuts)。调整字幕偏移有两组快捷键：

- `Ctrl + Left/Right` 或 `Shift + Left/Right`：将当前时间戳与前一条或后一条字幕对齐。
- `Ctrl + Shift + Left/Right`：将当前时间戳向前或向后移动 `100ms`。

通常可以按以下步骤找到正确的偏移量：

1. 等待角色开始说话。
2. 按 `Ctrl + Left/Right`，直到屏幕上出现与角色台词对应的字幕。
3. 按 `Ctrl + Shift + Right/Left`，直到字幕时间与台词精确同步。

## 悬浮界面 {#overlay-ui}

悬浮界面提供的按钮与上述键盘快捷键功能相同。

1. 滚动到最右侧区域的**中间**控制项。
2. 点击左侧或右侧按钮，将前一条或后一条字幕与当前时间戳对齐。
3. 点击并**按住**左侧或右侧按钮，将当前时间戳向前或向后移动 `100ms`。
