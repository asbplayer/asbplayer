# 离线使用 {#offline-usage}

得益于 [vite-pwa](https://vite-pwa-org.netlify.app/) 提供的 PWA 支持，<a href={project.urls.app}>网站</a>可以离线使用。下次在联网时访问网站，便会获取更新。

## 添加到主屏幕 {#add-to-home-screen}

作为渐进式 Web 应用，网站可以添加到 Android 设备的主屏幕。在浏览器菜单中点击“添加到主屏幕”。
