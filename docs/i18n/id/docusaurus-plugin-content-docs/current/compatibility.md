| Peramban                    | Wadah `mp4`     | Wadah `mkv`     | Wadah `avi`     |                                        H.264                                         |                                      H.265/HEVC                                      | Dolby Digital / Digital Plus (AC-3 / E-AC-3) | DTS / Dolby TrueHD / MLP |
| --------------------------- | :-------------: | :-------------: | :-------------: | :----------------------------------------------------------------------------------: | :----------------------------------------------------------------------------------: | :------------------------------------------: | :----------------------: |
| **Chromium-based browsers** |        ✓        |        ✓        |                 |                                          ✓                                           |         [Depends on platform/decoder](https://www.chromium.org/audio-video/)         |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Firefox**                 |        ✓        |        ✓        |                 | [Depends on OS codecs](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) | [Depends on OS codecs](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Safari**                  |        ✓        |                 |                 |                                          ✓                                           |                                          ✓                                           |                      ✓                       |        ✓ (FFmpeg)        |

Untuk item dalam matriks bertanda `✓ (FFmpeg)`, asbplayer otomatis mengonversi audio ke format yang dapat diputar. Peramban yang didukung dapat mulai memutar sambil konversi berlangsung, dengan lompatan waktu dibatasi pada audio yang tersedia; peramban lain menunggu hingga konversi selesai. <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>Pustaka FFmpeg yang dikompilasi untuk asbplayer</a> diunduh saat pertama kali digunakan dan disimpan untuk penggunaan offline.

### Layanan streaming dan deteksi takarir {#streaming-services-and-subtitle-detection}

:::tip
Untuk layanan streaming yang tidak tercantum di bawah, asbplayer dapat mencoba deteksi takarir umum dengan upaya terbaik, yang berfungsi di sekitar 85% situs web.

Anda dapat meminta parser khusus untuk situs web mana pun, meskipun parser umum dapat mendeteksi takarir, melalui <a href={`${project.urls.repo}/issues`}>issue</a> atau mengirimkan implementasi sendiri dalam <a href={`${project.urls.repo}/pulls`}>PR</a> di GitHub.
:::
