# Penggunaan offline {#offline-usage}

<a href={project.urls.app}>Situs web</a> dapat digunakan secara offline berkat dukungan PWA melalui [vite-pwa](https://vite-pwa-org.netlify.app/). Pembaruan akan diunduh saat situs web dibuka kembali dengan koneksi internet.

## Tambahkan ke layar utama {#add-to-home-screen}

Sebagai aplikasi web progresif, situs web dapat ditambahkan ke layar utama perangkat Android Anda. Buka menu peramban, lalu ketuk "Tambahkan ke layar utama".
