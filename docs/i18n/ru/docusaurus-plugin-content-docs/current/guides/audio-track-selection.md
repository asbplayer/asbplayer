# Выбор аудиодорожки {#audio-track-selection}

Некоторые видеофайлы содержат несколько аудиодорожек. На сайте выбор аудиодорожки доступен, если включён флаг **Experimental Web Platform features** на странице `chrome://flags` (или аналогичной странице текущего браузера).

:::warning
На момент написания этой статьи флаг **Experimental Web Platform features** полностью нарушает работу расширения в потоковом видео (на некоторых, а возможно, и на всех сайтах). Включайте его на свой страх и риск.
:::
