# Аннотации {#annotation}

asbplayer может добавлять к субтитрам аннотации, помогающие в изучении языков. Доступны следующие функции:

- **Оформление слов**: цвет, подчёркивание, обводка и другие эффекты в зависимости от состояния слова
    - состояния известных слов можно получать из Anki и WaniKani, синхронизировать с ними или отслеживать локально в asbplayer (доступны функции импорта и экспорта слов)
- **Аннотации чтения**: отображение чтения над каждым словом или в зависимости от его состояния
- **Аннотации частотности**: частотный ранг под каждым словом или в зависимости от его состояния (нужен хотя бы один частотный словарь с ранжированием)
- **Аннотации тонового акцента**: отображение схемы акцента над фуриганой или словами, записанными каной (нужен хотя бы один словарь тоновых акцентов)
- **Аннотации определений**: краткие определения или пояснения для каждого слова
- **Статистика и понимание**: сведения об известных вам словах в текущем медиафайле.
- **Адаптивное воспроизведение**: использует режимы воспроизведения и данные аннотаций для оптимизации обучения.
- **Обозреватель слов**: управление локальными словами и просмотр слов, синхронизированных из внешних источников.
- **И многое другое появится в будущих выпусках!**

:::info
Для аннотаций требуется настроенный экземпляр [Yomitan](https://yomitan.wiki/) и [yomitan-api](https://github.com/yomidevs/yomitan-api).

Если вы используете **локальную базу слов**, рекомендуем установить расширение asbplayer, чтобы браузер с меньшей вероятностью удалил сохранённые слова. Если установить расширение нельзя, периодически экспортируйте настройки и/или локальные слова в качестве резервной копии.
:::

## Настройка {#setup}

1. Откройте **Настройки** asbplayer.
2. Перейдите в раздел **Аннотации**.
3. Выберите дорожку, которую хотите настроить.
4. Настройте **URL Yomitan** для этой дорожки.
        - Требуется настроенный экземпляр [Yomitan](https://yomitan.wiki/) и [yomitan-api](https://github.com/yomidevs/yomitan-api).
        - Если URL указан неверно или недоступен, рядом с настройкой asbplayer покажет ошибку.
        - Для отображения частотности в Yomitan должен быть доступен хотя бы один частотный словарь с ранжированием.
5. (Для пользователей Anki) Настройте карточки, из которых нужно получать сведения о состоянии слов.
        - Обычно список [`Колоды Anki`](../reference/settings.md#anki-decks) следует оставить пустым, чтобы использовать все колоды; обычно достаточно фильтрации по полям.
        - [`Поля слов Anki`](../reference/settings.md#anki-word-fields) — поля заметки Anki, содержащие только нужное слово.
        - [`Поля предложений Anki`](../reference/settings.md#anki-sentence-fields) следует использовать только для заметок Anki без отдельного поля для слова (например, заметок с предложениями). Они используются как запасной вариант, если слова нет в полях слов Anki.
        - После настройки полей нажмите [`Перестроить базу слов Anki`](../reference/settings.md#re-build-anki-word-database), чтобы заполнить базу.
6. (Для пользователей WaniKani) Откройте [WaniKani > Настройки > Токены API](https://www.wanikani.com/settings/personal_access_tokens), чтобы создать токен для asbplayer.
        - Введите `asbplayer` в поле `Token Description`, оставьте все флажки `Permissions` снятыми: asbplayer нужен только доступ на чтение к вашей учётной записи WaniKani.
        - Нажмите `Generate token` и скопируйте созданный токен в поле [`Токен API WaniKani`](../reference/settings.md#wanikani-api-token).
        - После настройки токена API нажмите [`Перестроить базу слов WaniKani`](../reference/settings.md#re-build-wanikani-word-database), чтобы заполнить базу.
7. Включите нужные функции аннотаций для дорожки: оформление, чтение, частотность, тоновый акцент и другие. При необходимости измените остальные настройки.
8. Подробное описание параметров см. в разделе [Аннотации](../reference/settings.md#annotation) справочника настроек. Действия с клавиатуры перечислены в группе [Сочетания клавиш для аннотаций](../reference/settings.md#annotation-keyboard-shortcuts).
