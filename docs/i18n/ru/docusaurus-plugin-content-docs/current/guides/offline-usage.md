# Использование офлайн {#offline-usage}

<a href={project.urls.app}>Сайт</a> можно использовать офлайн благодаря поддержке PWA через [vite-pwa](https://vite-pwa-org.netlify.app/). Обновления загружаются при следующем посещении сайта с подключением к Интернету.

## Добавление на главный экран {#add-to-home-screen}

Как прогрессивное веб-приложение, сайт можно добавить на главный экран устройства Android. Откройте меню браузера и нажмите «Добавить на главный экран».
