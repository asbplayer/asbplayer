| **Firefox**                 |        ✓        |        ✓        |                 | [Dipende dai codec del sistema operativo](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) | [Dipende dai codec del sistema operativo](https://support.mozilla.org/en-US/kb/audio-and-video-firefox) |                  ✓ (FFmpeg)                  |        ✓ (FFmpeg)        |
| **Safari**                  |        ✓        |                 |                 |                                          ✓                                           |                                          ✓                                           |                      ✓                       |        ✓ (FFmpeg)        |

Per i formati indicati nella tabella con `✓ (FFmpeg)`, asbplayer converte automaticamente l'audio in un formato riproducibile. I browser supportati possono iniziare la riproduzione mentre la conversione prosegue, ma la ricerca è limitata all'audio già disponibile; gli altri devono attendere il completamento della conversione. La <a href={`${project.urls.repo}/blob/main/ffmpeg/README.md`}>libreria FFmpeg compilata per asbplayer</a> viene scaricata al primo utilizzo e memorizzata nella cache per l'uso offline.

### Servizi di streaming e rilevamento dei sottotitoli {#streaming-services-and-subtitle-detection}

:::tip
Per i servizi di streaming non elencati qui sotto, asbplayer può tentare un rilevamento generico dei sottotitoli con i migliori risultati possibili, che funziona su circa l'85% dei siti web.

Puoi sempre richiedere un parser dedicato per qualsiasi sito web, anche se il parser generico rileva i sottotitoli, aprendo una <a href={`${project.urls.repo}/issues`}>segnalazione</a> oppure inviando una tua implementazione tramite una <a href={`${project.urls.repo}/pulls`}>PR</a> su GitHub.
:::
